# BlackStrike — Guns & Ammunition (HTML version)

Inventory, point of sale, catalog by gun model, and printable compliance reports for a licensed firearms and ammunition dealer.

**Live site:** https://oticosven-byte.github.io/blackstrike/ — sign in with any username.

This repository is the **HTML-only version** of BlackStrike: every screen of the app as plain HTML/CSS/JavaScript with sample data,
so it runs on GitHub Pages. Browsing, search, filters, the 360° viewer and the product gallery work.
Buttons that save data show a "Demo mode" message, because saving needs PHP and a MySQL database (the XAMPP version).

Made from BlackStrike v2.3 (PHP 8 + MySQL).
